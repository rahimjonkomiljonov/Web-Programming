The problem

Same lecture, never spoken

You can see the same faces for a whole semester without saying hello.

Most apps start from looks

A photo and a swipe tell you nothing about whether you would get along.

Campus life has better reasons

A course, a club or a free hour makes the first message easy.

The idea

  • Only shared things count. Courses, clubs, free time, interests and values make the score.
  • Six people a day. A short list instead of an endless feed.
  • Every card explains itself. "You're both in Data Structures" tells you why you were introduced.
  • Four modes: Friends, Study buddy, Dating (needs its own consent) and Open.

The app: four tabs

Picks

Six people a day, each one explained.

Waves

Who waved at you, with an optional note.

Matches

Chat and plan a meetup with mutual waves.

Me

Edit your profile, privacy and data export.

Joining takes about three minutes: emailed six-digit code (no password), age check that keeps only the birth year, the overlap questions, then photos and a selfie checked by a human moderator.

How matching works

S(a,b) = 100 × ( wC·C + wK·K + wT·T + wI·I + wV·V )

C · Courses

Do you take the same course section? Sharing a section counts extra.

K · Clubs

Do you belong to the same clubs? Rarer clubs count more.

T · Free time

Do your weekly free hours line up?

I · Interests

Do you like the same things, such as photography or board games?

V · Values

How close are your answers to eight short agree/disagree statements?

Rare things count more: w(x) = ln( N / (1 + n) ). A club of 3 people has weight 3.22, a course of 60 people only 0.49. Ranking uses the harmonic mean of both people's scores, so a match must be good for both.

How it is built

Browser

React 19, Tailwind v4, Korean and English, swipe gestures, mobile first.

Server

Next.js 16 with the App Router and server actions. Every action checks permissions itself.

Matching engine

Plain TypeScript functions, rarity-weighted and property-tested.

Data

PostgreSQL with Prisma 7, emailed codes, photos in object storage.

About 47,000 lines of TypeScript, 49 database tables, 1,475 unit tests and 27 end-to-end suites.

Safety and privacy

  • Report, human decision, clear enforcement: warn, 7-day suspension or ban, with a reason and an appeal.
  • No ID numbers: only the birth year is kept after the age check.
  • Selfies are temporary: deleted within 7 days.
  • Chats stay private: never logged; moderators see only what a reporter attaches.
  • Encrypted preferences: who you'd like to date is never shown to moderators.
  • Delete means delete: 30-day grace period, then your identity is scrubbed.

Status and roadmap

  • Now: live at overlaps.tech, no invites yet; mobile app in progress.
  • First pilot: invite-only, at most 50 people, one campus.
  • Later: more campuses, Android and iPhone apps, chat photos.

What we learned

  • Small pure functions let property tests catch a real bug with duplicate items.
  • Never select it, don't just hide it: a field a role must not see should never be loaded for that role.
  • Test the real path, phone and desktop: browser tests found bugs unit tests could not.

The presentation uses a fictional campus (Hartwell University) with invented students and AI-generated portraits. Overlap is not open to the public yet.
