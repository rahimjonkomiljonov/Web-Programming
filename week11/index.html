E1

Your first component

Part 1 · components

A component is a function that returns JSX. Its name starts with a capital letter, so <Greeting /> calls the function instead of making an HTML tag. App reuses it three times.

Code

// Simplest possible React component
function Greeting() {
  return <h1>Hello, World!</h1>;
}

// Using it in another component
function App() {
  return (
    <div>
      <Greeting />
      <Greeting />
      <Greeting />
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('demo-hello-world')).render(<App />);

E2

JSX in practice: UserCard

Part 1 · JSX

JSX uses className instead of class, and anything in { } is JavaScript: the initials are worked out from the name, and the year comes from new Date().

Code

function UserCard({ name, role }) {
  const initials = name.split(' ').map(w => w[0]).join('');

  return (
    <div className="card">
      <div className="avatar">{initials}</div>
      <h2>{name}</h2>
      <p className="role">{role}</p>
      <p>Joined: {new Date().getFullYear()}</p>
    </div>
  );
}

function App() {
  return (
    <div className="user-cards">
      <UserCard name="Ada Lovelace" role="Mathematician" />
      <UserCard name="Grace Hopper" role="Rear Admiral" />
      <UserCard name="Alan Turing" role="Computer Scientist" />
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('demo-user-cards')).render(<App />);

E3

Passing and using props: ProfileCard

Part 2 · props

The parent passes a string, a number and a boolean. Strings go in quotes; other values go in { }. The child destructures them, shows [Verified] only when isVerified is true, and formats 1240 as 1,240.

Code

// Parent passes props
function App() {
  return (
    <ProfileCard
      name="Kim Minho"
      role="Frontend Developer"
      followers={1240}
      isVerified={true}
    />
  );
}

// Child receives and uses them
function ProfileCard({ name, role, followers, isVerified }) {
  return (
    <div className="profile">
      <h2>{name} {isVerified && '[Verified]'}</h2>
      <p>{role}</p>
      <p>{followers.toLocaleString()} followers</p>
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('demo-profile-card')).render(<App />);

E4

props.children: a wrapper Card

Part 3 · composition

Whatever goes between <Card> and </Card> arrives as the children prop, so one Card can wrap any content.

Code

// A reusable card wrapper
function Card({ title, children }) {
  return (
    <div className="card">
      <h3 className="card-title">{title}</h3>
      <div className="card-body">
        {children}
      </div>
    </div>
  );
}

// Use it to wrap anything
function App() {
  return (
    <Card title="Student Info">
      <p>Name: Park Jisoo</p>
      <p>Major: Computer Engineering</p>
      <button>Edit Profile</button>
    </Card>
  );
}

ReactDOM.createRoot(document.getElementById('demo-card')).render(<App />);

E5

Rendering lists with map()

Part 4 · lists

map() turns each student object into an <li>. Each item gets key={student.id}: a unique, stable id, not the array index.

Code

const students = [
  { id: 1, name: 'Lee Jungwoo', grade: 'A'  },
  { id: 2, name: 'Park Sohee',  grade: 'B+' },
  { id: 3, name: 'Kim Minho',   grade: 'A-' },
];

function StudentList() {
  return (
    <ul>
      {students.map(student => (
        <li key={student.id}>
          {student.name} -- {student.grade}
        </li>
      ))}
    </ul>
  );
}

ReactDOM.createRoot(document.getElementById('demo-student-list')).render(<StudentList />);

E6

Conditional rendering: Alert and Dashboard

Part 4 · conditions

All three ways from the slide: Alert returns null when there is no message, uses a ternary for the label, and Dashboard uses &&. I made the Log in button work, so you can see both branches; that needs one useState call, which is Monday's topic.

Code

function Alert({ type, message }) {
  if (!message) return null; // render nothing

  return (
    <div className={"alert alert-" + type}>
      {type === 'error' ? 'ERROR:' : 'OK:'} {message}
    </div>
  );
}

function Dashboard({ user, onLogin, onLogout }) {
  return (
    <div className="dashboard">
      {user && <p>Welcome, {user.name}!</p>}
      {!user && <p>Please log in.</p>}
      {user
        ? <button className="secondary" onClick={onLogout}>Log out</button>
        : <button onClick={onLogin}>Log in</button>}
    </div>
  );
}

// The button needs a value that changes, so App keeps `user` in state
// (useState is Monday's topic; here it only flips user between null and an object).
function App() {
  const [user, setUser] = React.useState(null);

  return (
    <div>
      <Alert
        type={user ? 'success' : 'error'}
        message={user ? 'Logged in as ' + user.name + '.' : 'You are not logged in.'}
      />
      <Alert type="error" message="" /> {/* empty message: renders nothing */}
      <Dashboard
        user={user}
        onLogin={() => setUser({ name: 'Jisoo' })}
        onLogout={() => setUser(null)}
      />
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('demo-conditional-rendering')).render(<App />);

Code challenge

CC

Build a ProductCard

both bonuses done

Task: a ProductCard that takes name (string), price (number, KRW), rating (0 to 5) and inStock (boolean). Bonus 1: show the rating as “4.5 / 5 stars”. Bonus 2: show “Out of Stock” when !inStock.

Following the best-practices slide, each part has one job: PriceTag formats the price, StarRating draws the stars (and keeps the rating between 0 and 5), StockBadge picks the label. Defaults cover missing props; the third card is <ProductCard /> with no props at all.

Code

// Code challenge: a ProductCard built from small, single-purpose parts.

// 89000 -> "89,000원"
function PriceTag({ price }) {
  return <p className="price">{price.toLocaleString('ko-KR')}원</p>;
}

// 4.5 -> "★★★★½" plus the bonus text "4.5 / 5 stars"
function StarRating({ rating }) {
  const value = Math.min(5, Math.max(0, rating)); // keep it between 0 and 5
  const full = Math.floor(value);
  const half = value - full >= 0.5;
  const empty = 5 - full - (half ? 1 : 0);

  return (
    <div className="rating">
      <span className="stars" aria-hidden="true">
        {'★'.repeat(full)}{half && '½'}{'☆'.repeat(empty)}
      </span>
      <p>{value} / 5 stars</p>
    </div>
  );
}

// Bonus 2: "Out of Stock" when !inStock
function StockBadge({ inStock }) {
  return inStock
    ? <p className="stock in">In Stock</p>
    : <p className="stock out">Out of Stock</p>;
}

function ProductCard({ name = 'Unnamed product', price = 0, rating = 0, inStock = false }) {
  return (
    <article className={'product-card' + (inStock ? '' : ' sold-out')}>
      <h3>{name}</h3>
      <PriceTag price={price} />
      <StarRating rating={rating} />
      <StockBadge inStock={inStock} />
    </article>
  );
}

function App() {
  return (
    <div className="products">
      {/* the expected usage from the slide */}
      <ProductCard
        name="Wireless Earbuds"
        price={89000}
        rating={4.5}
        inStock={true}
      />
      <ProductCard name="Mechanical Keyboard" price={129000} rating={4} inStock={false} />
      {/* no props at all: every default kicks in */}
      <ProductCard />
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('demo-product-card')).render(<App />);
