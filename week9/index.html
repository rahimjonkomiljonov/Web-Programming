Lighthouse screenshots

These are screenshots of the real Lighthouse reports; the audited URL is in the header of each one. The "before" runs use the code from before the fixes (commit 1cf03b3), which I served on localhost:8802 because that version was never published. The "after" runs use the live GitHub Pages URLs.

Fixes

These are the four failing audits Lighthouse reported, and what I changed for each.

  1. Added a <title> (document-title) to 11 pages: week2/ex2, ex3, ex4, ex7 and week3/ex1 to ex7. Four of the Week 2 pages were bare fragments with no <html> or <head>, so they now have a full document.
  2. Added lang="en" (html-has-lang) to the same four Week 2 pages, so screen readers pick the right pronunciation.
  3. Fixed colour contrast (color-contrast) on two pages. On week3/ex3.html white labels on the colour swatches measured 2.14:1 to 3.76:1 in the report, so the labels are now black. On week3/ex8.html the footer text was #587078 on #1e293b (2.78:1) and is now #cbd5e1. Both need at least 4.5:1.
  4. Enlarged touch targets (target-size). The menu links on week2/ex3.html were 17px tall (the minimum is 24px) and are now at least 24px.
  5. Added a skip link (WCAG 2.4.1, Level A). It sits at the top of the home page and the group project page. For every other page, site-nav.js adds one automatically. It stays off-screen until the first Tab, then jumps to #main-content. I also wrapped the content of the fixed pages in a <main> landmark; Lighthouse did not flag that one, it is just good practice.
